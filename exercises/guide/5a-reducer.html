The reducer is where your model stops being a sketch. Three pure entry points, apply_event, apply_snapshot and tick, change a Board and return effects. After every change the truth is recomputed and handed to Shown::settle. Every behaviour below is observed through four things only: truth (board.phase(agent)), shown (agent.shown.phase), the effects returned, and the agent's fields.

phase 03

The reducer

T07–T09 · about 4¼ hours. When this phase is done, a scripted story of an agent's life produces the right chip at every step: typing, tools, an approval, an Escape, a rate limit, a subagent, a /clear, and death.

Rules that hold for every transition in this phase.
  • Nothing that changes nothing publishes. A duplicate event returns no effects at all.
  • At most one PublishState, and it comes last. A history entry always implies a publish.
  • A history entry is written exactly when shown moves, recording from, to, and how long the old phase was held.
  • last_event is stamped only when the event changed something.
  • Time comes only from the input. The reducer never reads a clock.

  1. cargo test --test t07_turns -- unknown_for_a_discovered idle_on_session_start Needs settle, limits_for and the SessionStarted arm. Swap the three T08 helpers for placeholders now.
  2. cargo test --test t07_turns -- route tracked adopt Try route returning Option<&mut Agent> first, and keep the compiler error for kata 1.
  3. cargo test --test t07_turns -- previous_session rotates
  4. cargo test --test t07_turns -- working_at_once same_turn mid_turn turn_ends different_turn
  5. cargo test --test t07_turns -- stopped turn_failure
  6. cargo test --test t07_turns -- dispatched settled settles fails
  7. cargo test --test t07_turns -- dies cwd liveness
  8. Start with last_event, a replay on an unobserved agent, and interrupt-before-Stop against Stop-before-interrupt.
  9. cargo test --test t07_turns && cargo test --lib -- model:: Grading adds a hidden suite of 31 tests. Where yours and it disagree, one of them has found a spec ambiguity, and that's worth talking about.
Watch for
  • Holding &mut Agent while reading the account's limits. Destructure the board first.
  • Leaving a turn from inside a match on that same turn. Know when the borrow of its fields ends.
