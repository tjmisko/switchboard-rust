Before anything can be ingested, the crate needs to talk about itself. Identifiers have to pass for strings without losing their types. Every boundary needs an error that says which of four things went wrong: the bytes never arrived, they weren't JSON, the JSON had the wrong shape, or the peer refused.

Desired behaviour

Every id (SessionId, ToolUseId, SubagentId, and the rest) behaves like a string wherever a string is only being read, and like its own type everywhere else.

  • A &SessionId can be passed to a function taking &str, and str methods can be called on it directly.
  • A BTreeMap or HashMap keyed by an id can be queried with a plain &str, without allocating.
  • Option<SessionId> becomes Option<&str> in one call.
  • Formatting prints the bare id. Building one from a String reuses its allocation.

Desired behaviour · vocabularies

  • Every Phase parses from the name it prints (attention … idle). The Go daemon's permission is rejected, and the error prints as unknown phase: "permission".
  • Start sources are startup · resume · clear · compact. Denial kinds are user-rejected · permission-rule · automode-blocked · automode-unavailable · interrupted. Matching is case-sensitive.

Desired behaviour · socket frames

Fields are checked in the order cmd, event, pid, session_id. A required field that's absent is missing. A field that's present with the wrong type or range is wrong type, whether or not the field is required. Unknown extra fields are ignored.
