# T09 katas

## 1. Why not `replace_waits(agent.waits, ..)`

`agent` is a `&mut Agent`. Passing `agent.waits` by value would move the
map out of the struct, and you cannot move a field out from behind a
reference (E0507, "cannot move out of `agent.waits` which is behind a
mutable reference"): for the duration of the call the `Agent` would have
an uninitialised field, and nothing in the type system tracks that partial
state through a `&mut`. `std::mem::take(&mut agent.waits)` swaps an empty
`BTreeMap` (its `Default`) into the field and hands the old map back by
value, so `agent` is whole at every instant and the old `Wait`s can be
consumed with `remove`.

## 2. Which sources in `deadlines` borrow

Owned, computed up front as `Option<Instant>` (an `Instant` is `Copy`, so
the value carries no borrow even though it was read through `agent`):
the pending promotion (`agent.shown.pending.as_ref().map(|e| e.promote_at)`),
the stale turn (`stale_turn_deadline(agent)`), and the compaction deadline.

Borrowing from `agent` for as long as the returned iterator lives: the
three lazy iterators over its maps, `agent.waits.values().map(..)`,
`agent.prompts.unjoined.iter().map(..)` and
`agent.subagents.rows.values().filter_map(..)`. They hold `&BTreeMap` /
`&Vec` borrows and only produce `Instant`s when driven. Those three are
why the return type needs `+ '_`; the first three alone could be returned
as `'static` values.

## 3. Why a snapshot escalation promotes after 6 s, not 10

The dwell is fixed when the escalation is first recorded. `Shown::settle`
computes `promote_at = now + dwell` from the confidence of the input that
raised the truth (`Snapshot` gives `SNAPSHOT_DWELL`, 6 s) and stores it in
`pending`. On a later call for the same target phase, the match arm
`Some(e) if e.to == truth` only compares `now >= e.promote_at`; the
confidence passed on that call is not consulted. The tick's `Inferred`
would only matter if there were no escalation pending, or if the truth had
moved to a different phase, in which case a fresh clock starts with the
tick's dwell. So a snapshot-raised escalation keeps its 6 s deadline
whoever promotes it.
