    EXPLAIN IT IN TEN MINUTES

    Six sentences to hold the system in your head.

    1. Sources observe the world; adapters translate observations into a shared vocabulary.
    2. Events describe edges, snapshots describe a scope at a time, and merge rules preserve fresher evidence.
    3. One task owns the board and applies the reducer sequentially.
    4. An agent stores independent facts; a fold computes its phase and display rules control what you see.
    5. Effects request I/O outside the reducer; new observations return through the inbox.
    6. Consumers receive derived views, while provider quirks and OS details stay at the edges of the intended design.
